📋 Saisie automatique dans ADE

Installation (une seule fois, sur le PC) :

  1. Affichez la barre de favoris de Chrome : Ctrl + Maj + B.
  2. Glissez ce bouton vert dans la barre de favoris (ne cliquez pas dessus ici) :

    Saisie ADE

Utilisation après chaque cours :

  1. Sur le téléphone, dans l'appli Présence NFC : étape ④ → « 💻 Code pour ADE » → envoyez-vous le code (mail, Teams…) et copiez-le sur le PC.
  2. Dans UPplanning : clic droit sur le cours → Assiduités → Assiduité.
  3. Cliquez sur le favori Saisie ADE et collez le code.
  4. Le script trouve la séance (même date et même heure) et passe les absents en « Absent » et les retardataires en « Retard ».
  5. Vérifiez, puis cliquez vous-même sur Enregistrer. Le script n'enregistre jamais à votre place.

Un seul code peut contenir plusieurs séances : collez le même code pour chaque cours de la journée ou de la semaine. Le script fonctionne uniquement dans votre navigateur, avec votre propre connexion UPplanning. Il n'envoie aucune donnée ailleurs.
