📋 Saisie automatique dans ADE

Le téléphone (appli Présence NFC) envoie les absents et les retards dans votre dépôt GitHub privé. Sur le PC, le favori « Saisie ADE » les lit et remplit la fenêtre d'assiduité d'ADE.

1. Créer le dépôt privé (une seule fois)

  1. Ouvrez github.com/new.
  2. Nom du dépôt : presence-data. Cochez Private, puis Create repository.

2. Créer le jeton d'accès (une seule fois)

  1. Ouvrez github.com/settings/personal-access-tokens/new.
  2. Token name : Presence NFC. Expiration : 1 an (366 days).
  3. Repository access : Only select repositories → choisissez presence-data.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Generate token, puis copiez le jeton (il commence par github_pat_). Il ne sera plus affiché : gardez-le jusqu'aux étapes 3 et 4.

3. Sur le téléphone (appli)

  1. Onglet Réglages → Synchronisation avec le PC : dépôt Sobysun/presence-data, collez le jeton, puis Enregistrer et tester.

4. Sur le PC (Chrome)

  1. Affichez la barre de favoris : Ctrl + Maj + B. Supprimez l'ancien favori « Saisie ADE » s'il existe.
  2. Glissez ce bouton dans la barre de favoris :

    Saisie ADE

  3. Au premier clic dans UPplanning, le favori demande le dépôt et le jeton : collez le même jeton.

Utilisation

  1. Dans UPplanning, cliquez sur le favori Saisie ADE : un panneau liste les séances à saisir.
  2. Clic droit sur un cours → Assiduités → Assiduité. Dans le panneau, la séance correspondante est entourée en vert.
  3. Appuyez sur la séance dans le panneau :
    🟠 orange = remplie : vérifiez puis cliquez sur Enregistrer dans ADE. La séance disparaît et le téléphone la marque ✅.
    🔴 rouge = problème (mauvaise fenêtre ouverte, ou étudiant introuvable) : le panneau explique quoi faire.
  4. Passez à la séance suivante.

Le script ne clique jamais sur « Enregistrer » à votre place. Il tourne uniquement dans votre navigateur, avec votre connexion UPplanning, et ne communique qu'avec votre dépôt privé. Le panneau peut être déplacé par sa barre bleue.

En cas de blocage

Si le favori affiche « impossible de charger le script », installez à la place cette version autonome (à réinstaller après chaque mise à jour) :
